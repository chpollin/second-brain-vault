# Fixture Concept Beta

## Summary

The anchor value is the fictional value a run starts from. It is fixed before the run and never changes.

## Key Points

- The anchor value is fixed before the run
- It never changes during a run

## Synthesis

The anchor value gives the baseline against which [[Fixture Concept Alpha]] is measured.
