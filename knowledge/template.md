# Template

This repository is the reusable vault template for Second Brain, whose [general function](project.md) is bringing together and working with knowledge held by a person, about a person or within a domain. It derives from a maintained personal research vault and supplies synthetic examples. The owner's personal research content remains unpublished. Since 2026-10-31 this repository is its own maintenance source, see [maintenance and distribution](integration.md#maintenance-and-distribution).

The maintained description is organized by the question it answers.

- [Project](project.md) defines the purpose, audience and evidence boundary.
- [Specification](specification.md) defines the components, constraints and checks.
- [Integration](integration.md) defines ownership, separate tools and distribution.
- [Design](design.md) describes the method page and knowledge explorer.
- [Journal](journal.md) records derivation and subsequent decisions.
- [Skill evaluation](skill-evaluation.md) records the bounded synthetic trials.

This address remains valid for references from other repositories. Start with the [knowledge index](INDEX.md) for further work.
