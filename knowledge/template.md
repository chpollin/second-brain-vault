# Template

This repository is the reusable vault template for Second Brain, a personal research environment for working with AI agents. It abstracts a maintained personal vault through synthetic examples and excludes its owner's personal research content. The maintenance source remains `knowledge-structures/second-brain-vault`, with a separate public snapshot.

The maintained description is organized by the question it answers.

- [Project](project.md) defines the purpose, audience and evidence boundary.
- [Specification](specification.md) defines the components, constraints and checks.
- [Integration](integration.md) defines ownership, separate tools and distribution.
- [Journal](journal.md) records derivation and subsequent decisions.
- [Skill evaluation](skill-evaluation.md) records the bounded synthetic trials.

This address remains valid for references from other repositories. Start with the [knowledge index](INDEX.md) for further work.
