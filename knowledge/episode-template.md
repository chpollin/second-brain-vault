# Episode record template

Use with the [evaluation protocol](evaluation.md). Copy into the authorized study location before an actual episode. Replace fields only from observed evidence. `Unrecorded` means no evidence has been entered. Record `Not applicable` with a reason when a field does not apply. Use the comparison section only for a commissioned comparison. This blank template reports no study execution.
