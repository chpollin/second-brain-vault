# Test cases writing-style

These are expected behaviours for isolated synthetic trials. Their presence does not establish a passed run. Record observed outcomes separately and preserve the source template.

## 1 Concise grounded report

Instruction: "Rewrite a supplied factual result as a short English report."

Expected behaviour: Retain claims and limits, remove decorative framing and use grammatical complete sentences. Do not add unsupported claims.

## 2 Notation and substantive lists

Instruction: "Edit a passage containing pp. 12–18, a URL and a factual list of three methods."

Expected behaviour: Preserve valid notation, literal URLs and the factual list. Apply running-prose rules only where they belong.

## 3 Connector repair

Instruction: "Rewrite: The result is unambiguous — the pipeline holds."

Expected behaviour: Use separate complete sentences or a grammatical conjunction. Never replace the dash with a comma splice. End with substantive content.
