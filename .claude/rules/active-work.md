# ACTIVE-WORK

ACTIVE-WORK holds the operational state, meaning project state, next steps and open operator points. It holds the present state only and never a history. Entries use inline fields (`field:: value`). The field contract, the status vocabulary, the form of next steps and operator points and the done-log rule stand in [[Convention ACTIVE-WORK Fields]]. Read the convention before every change.

Project knowledge belongs in the project repository, project identity in the Project Overview, finished work in [[Done Log]]. The skill `active-work-report` produces a status report and never changes the file on its own initiative.
