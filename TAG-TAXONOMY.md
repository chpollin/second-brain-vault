# TAG-TAXONOMY

> [!info] Read trigger
> Controlled vocabulary. Consult before assigning any tag. Every tag used in the vault is defined here first, and the commit check rejects an unregistered tag.

## Functional tags

Functional tags say what kind of document it is, independent of any domain.

`knowledge, workflow, use-case, moc, hub, template, glossary, original, literature, media, fixture`

## Thematic tags

Thematic tags name a knowledge domain, one per domain.

- `example-domain` — placeholder for the tag of one knowledge domain

## Rules

Tags are broad categories. A specific concept is linked and never tagged. Tags are lowercase-hyphenated, two to four per document. A new tag is registered here before first use, with one line that says what it covers.
