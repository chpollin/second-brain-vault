# Archival Master

An archival master is the copy of a digital object that is preserved unchanged. It keeps as much information as the source allows, so later copies can be made from it.

Work happens on an [[Access Copy]]. The master's [[File Format]] is chosen for longevity, not convenience. Source: [[Scan Protocol 2025]].
