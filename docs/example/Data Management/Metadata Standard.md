# Metadata Standard

A metadata standard fixes which facts describe a file and how they are written, such as title, creator, date and rights. It makes data findable, one of the [[FAIR Principles]]. The team's field list was introduced in [[Slides Data Workshop]]. Rights are a required field since testing the [[Online Presentation Photo Archive]].
