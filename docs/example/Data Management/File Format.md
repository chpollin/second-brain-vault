# File Format

A file format fixes how content is encoded in a file. For long-term keeping, open and widely documented formats are preferred, because they can still be read when today's software is gone.

The choice differs for an [[Archival Master]] and an [[Access Copy]]. The team's scanning settings stand in [[Scan Protocol 2025]]. A format decision is recorded once, see [[Decision Image Master Format]].
